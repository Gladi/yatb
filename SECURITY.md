# Security policy

Please **do not** report security problems in public issues.

Use GitHub's private vulnerability reporting instead: **Security → Report a vulnerability** in this repository.
Include what is affected, how to reproduce it and what an attacker could do. You will get an answer as soon as
possible; please give us reasonable time to fix the problem before you publish details.

In scope: the bot, the dashboard, the internal API and the website generator in this repository, and the reference
instance at yatb.gladi.de. Out of scope: denial of service, spam, and problems in Discord or the translation
providers themselves.
