Für Server-Admins

YATB ist ein privater Bot. Wenn er auf deinem Server ist, richtest du ihn so ein. Alle Befehle liegen unter /yatb und sind nur für Admins sichtbar.

Einrichtung in 5 Schritten

  1. Rechte prüfen. In jedem verbundenen Kanal braucht YATB: View Channel, Read Message History, Manage Webhooks, Create Public Threads, Send Messages in Threads, Manage Threads, Add Reactions.
  2. Kanäle verbinden. Kanäle mit demselben Bridge-Namen werden ineinander übersetzt:
    /yatb bridge add chat #english English
    /yatb bridge add chat #deutsch German
    Foren- und Medien-Kanäle funktionieren genauso - immer Forum mit Forum. Fehlende Tags legt YATB selbst an, wenn es im Forum Kanäle verwalten darf.
  3. API-Keys hinzufügen (optional). Ohne Keys nutzt YATB LibreTranslate. Für bessere Qualität Keys mit /yatb keys add hinterlegen - siehe API-Keys.
  4. Log-Kanal festlegen. /yatb log set - dort meldet YATB Verbrauchswarnungen, Probleme mit Keys und Änderungen.
  5. Mitglieder informieren. Verlinke die Anleitung für Mitglieder oder ergänze eine kurze Regel, zum Beispiel:
    Übersetzungen (YATB): In verbundenen Kanälen übersetzt der Bot YATB Nachrichten automatisch und postet sie unter deinem Namen. Dafür können sie an externe Dienste (z. B. KI, Google) gehen. Texte werden nicht gespeichert. Nur lokal übersetzen: /yatb-user privacy

/yatb status zeigt die Übersetzungskette deines Servers und den Zustand jedes Dienstes.

Die Übersetzungskette

Für jede Nachricht probiert YATB die Dienste in dieser Reihenfolge und nimmt das erste gute Ergebnis:

  1. KI-Anbieter mit euren Keys - die Gruppe mit besserer Qualität zuerst, kostenlose Keys vor bezahlten
  2. Google Translate
  3. Azure Translator
  4. LibreTranslate auf unserem eigenen Server - immer verfügbar
  5. [Raw] - der Originaltext, wenn nichts anderes geklappt hat

Jede Antwort wird geprüft (Erwähnungen, Links, Formatierung). Eine schlechte Antwort, ein Fehler oder ein ausgeschöpftes Limit führt zum nächsten Dienst; ein gestörter Dienst wird eine Weile übersprungen. Mitglieder mit Nur lokal bekommen immer LibreTranslate.

Verbrauch, Limits und Budget

  • Kostenlose Keys: YATB zählt den Verbrauch gegen die Gratis-Limits des Anbieters pro Minute, Tag und Monat.
  • Bezahlte Keys: Du legst ein Monatsbudget in USD oder EUR fest. YATB schätzt die Kosten anhand der Listenpreise - lege zusätzlich beim Anbieter ein Ausgabenlimit fest.
  • Tageslimits laufen um 00:00 UTC zurück, Monatslimits am 1. um 00:00 UTC.
  • Warnungen bei 90, 95 und 100 % gehen in den Log-Kanal. Ist ein Key aufgebraucht, übernimmt der nächste Dienst.
  • Wird derselbe Key auf mehreren Servern genutzt, zählt der Verbrauch gemeinsam. Andere Server werden nie genannt.
  • /yatb keys list zeigt den Verbrauch je Key, /yatb keys edit ändert Stufe, Budget und Limit.

Foren- und Medien-Kanäle

  • Foren verbindest du wie Textkanäle, z. B. /yatb bridge add forum #forum-en English. Eine Bridge enthält entweder Foren oder Textkanäle, nie beides. Medien-Kanäle funktionieren genauso.
  • Ein neuer Beitrag erscheint in jedem anderen Forum der Bridge - mit übersetztem Titel und Text, passenden Tags und unter dem Namen der Verfasserin oder des Verfassers. Antworten, Bearbeitungen, Löschungen und Reaktionen im Beitrag werden gespiegelt.
  • Umbenennen, Tags ändern, Schließen oder Sperren des Original-Beitrags wird in die Kopien übernommen.
  • Tags werden 1:1 zugeordnet. Fehlende Tags legt YATB selbst an (übersetzter Name, gleiches Emoji), wenn es das Recht Kanäle verwalten hat - sonst werden nur gleichnamige Tags zugeordnet. Discord erlaubt 20 Tags pro Forum.

Wo du Kanäle verwalten vergibst:

  • Auf der Kategorie der Foren (empfohlen): Alle Foren darin sind abgedeckt, auch neue, und der Rest des Servers bleibt geschützt.
  • Auf jedem Forum einzeln: am engsten, aber jedes neue Forum braucht es wieder.
  • Serverweit (Bot-Rolle oder Einladungslink): am bequemsten, aber der Bot könnte dann jeden Kanal ändern oder löschen - würde sein Token je gestohlen, wäre der Schaden viel größer.

So sind die Keys geschützt

Keys werden in einem privaten Discord-Formular eingegeben, nie als Befehlsoption. Sie werden verschlüsselt gespeichert (AES-256-GCM, getrennt je Server) und nie wieder angezeigt - nur die letzten 4 Zeichen. Diese Website zeigt keine Keys an und nimmt keine an.

Alle Befehle

BefehlBeschreibung
/yatb infoAnleitung und Übersicht aller Befehle
/yatb guideSo bekommst du einen API-Key für einen Übersetzungsdienst
/yatb channelsWie viele Kanäle dieser Server belegt (Discord-Limit: 500)
/yatb statusÜbersetzungskette, Verbrauch und Zustand der Dienste dieses Servers
/yatb bridge addKanal zu einer Übersetzungs-Bridge hinzufügen
/yatb bridge removeKanal aus seiner Bridge entfernen
/yatb bridge listAlle Bridges dieses Servers anzeigen
/yatb keys addAPI-Key hinzufügen (privates Formular, verschlüsselt gespeichert)
/yatb keys editEinstellungen eines Keys ändern (der Key selbst wird nie angezeigt)
/yatb keys listAPI-Keys dieses Servers und ihren Verbrauch anzeigen (nie die Keys selbst)
/yatb keys removeAPI-Key von diesem Server entfernen
/yatb log setKanal für Benachrichtigungen festlegen (Verbrauch, Key-Probleme, Änderungen)
/yatb log clearBenachrichtigungskanal ausschalten
/yatb resetAlle Bridges, Keys und Einstellungen dieses Servers löschen
/yatb uninstallAlle Daten dieses Servers löschen und den Bot entfernen
/yatb-user privacyFestlegen, wer deine Nachrichten übersetzen darf (gilt auf allen Servern)
/yatb-user helpWas dieser Bot mit deinen Nachrichten macht

YATB entfernen

/yatb reset löscht alle Bridges, Keys und Einstellungen deines Servers. /yatb uninstall löscht alle Daten deines Servers, und der Bot verlässt ihn.
