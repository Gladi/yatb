Über Sprachgrenzen hinweg schreiben auf Discord

YATB - Yet Another Translation Bot - verbindet Kanäle in verschiedenen Sprachen. Alle schreiben in ihrer eigenen Sprache, YATB postet die Übersetzung in den anderen Kanälen, mit Name und Avatar der Verfasserin oder des Verfassers.

  • 7 Sprachen
  • Keine Nachrichtentexte gespeichert
  • Privater Bot

Was YATB kann

Natürliche Übersetzungen

KI-Übersetzung, die das Gespräch versteht: Slang, Gaming-Begriffe und kurze Antworten werden richtig übersetzt. Fällt ein Dienst aus, übernimmt der nächste.

Behält die Discord-Formatierung

Fett, Listen, Zitate, Spoiler, Emojis, Erwähnungen und Links bleiben erhalten. Echter Code wird nicht übersetzt.

Spiegelt das Gespräch

Antworten, Bearbeitungen, Löschungen, Reaktionen und Threads werden in alle verbundenen Kanäle übernommen. Auch Ankündigungen aus gefolgten Kanälen werden übersetzt.

Datenschutz von Anfang an

Es werden keine Nachrichtentexte gespeichert. Jedes Mitglied kann festlegen, dass seine Nachrichten nur auf unserem eigenen Server übersetzt werden.

Eigene Keys, eigenes Budget

Server-Admins hinterlegen ihre eigenen API-Keys in einem privaten Formular. Die Keys werden verschlüsselt gespeichert und nie wieder angezeigt. Limits und Budget-Warnungen inklusive.

Immer eine Übersetzung

Ganz ohne Keys übersetzt YATB mit LibreTranslate auf unserem eigenen Server - kostenlos, und nichts verlässt den Server.

So funktioniert es

  1. Admins verbinden Kanäle - zum Beispiel #english und #deutsch - zu einer Bridge.
  2. Mitglieder schreiben einfach in ihrer Sprache. Befehle sind nicht nötig.
  3. YATB postet die Übersetzung innerhalb weniger Sekunden in den anderen Kanälen.

Kann ich YATB zu meinem Server hinzufügen?

Im Moment nicht. YATB ist ein privater Bot und läuft nur auf ausgewählten Servern. Wenn YATB schon auf deinem Server ist, findest du hier die Anleitungen für Mitglieder und für Admins.
