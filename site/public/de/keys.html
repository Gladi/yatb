API-Keys besorgen

Mit API-Keys werden die Übersetzungen besser als mit dem kostenlosen LibreTranslate. Jeder Key gehört dir bzw. deinem Server - YATB nutzt ihn nur für deinen Server und speichert ihn verschlüsselt.

  • Lege im Konto des Anbieters zusätzlich zum Budget in YATB ein Ausgabenlimit fest.
  • Wo möglich, schalte Zero Data Retention ein bzw. das Training mit deinen Daten aus.
  • Keys hinzufügen mit /yatb keys add: Anbieter wählen, dann den Key in das private Formular einfügen.

Google Gemini KI-Anbieter

Schritte

  1. Öffne aistudio.google.com und melde dich mit deinem Google-Konto an.
  2. Lege ein Google-Cloud-Projekt an oder wähle eines und aktiviere die Abrechnung - die kostenlose Stufe darf für Nutzer im EWR, in UK und der Schweiz nicht genutzt werden.
  3. Get API key → Create API key für dieses Projekt.
  4. /yatb keys add ausführen, Google Gemini wählen und den Key einfügen.

Tarif

Nur bezahlte Keys (Projekt/Konto mit Abrechnung) sind nutzbar.

Datenschutz

Nur Keys mit aktivierter Abrechnung - die Gratis-Stufe darf für Nutzer im EWR, im Vereinigten Königreich und in der Schweiz nicht verwendet werden. Bezahlte Stufe: Google nutzt die Inhalte nicht zur Verbesserung seiner Produkte; Anfragen werden für begrenzte Zeit protokolliert, um Missbrauch zu erkennen. Verarbeitung durch Google weltweit. Mistral KI-Anbieter

Schritte

  1. Melde dich bei console.mistral.ai an.
  2. Wähle unter Billing einen bezahlten Tarif (der kostenlose Experiment-Tarif darf deine Daten zum Training nutzen).
  3. API Keys → Create new key.
  4. /yatb keys add ausführen, Mistral wählen und den Key einfügen.

Tarif

Kostenlose und bezahlte Keys sind möglich. Bei kostenlosen Keys gelten die Limits des Anbieters, bei bezahlten legst du ein Monatsbudget fest.

Datenschutz

Mistral AI (Frankreich). Kein Training mit deinen Inhalten - außer eine Produkteinstellung erlaubt es: In der Mistral-Konsole unter Privacy die Nutzung von API-Daten zur Verbesserung ausschalten. Im kostenlosen Tarif können Daten zum Training genutzt werden, wenn du nicht widersprichst. Ein Auftragsverarbeitungsvertrag (DPA) ist verfügbar, Zero Data Retention auf Antrag. Datenschutzangaben des Anbieters

Groq KI-Anbieter

Schritte

  1. Melde dich bei console.groq.com an.
  2. Empfohlen: Unter Settings → Data Controls die Datenspeicherung abschalten (Zero Data Retention).
  3. API Keys → Create API Key.
  4. /yatb keys add ausführen und Groq wählen. Der kostenlose Tarif hat niedrige Limits (etwa 30 Anfragen pro Minute).

Tarif

Kostenlose und bezahlte Keys sind möglich. Bei kostenlosen Keys gelten die Limits des Anbieters, bei bezahlten legst du ein Monatsbudget fest.

Datenschutz

Groq speichert Anfragedaten standardmäßig nicht; Protokolle zur Fehlersuche oder bei Missbrauch werden bis zu 30 Tage aufbewahrt. Zero Data Retention kann jeder unter Data Controls einschalten. Die Daten liegen in den USA. Datenschutzangaben des Anbieters

Novita KI-Anbieter

Schritte

  1. Melde dich bei novita.ai an und lade Guthaben auf (es gibt keinen kostenlosen Tarif).
  2. Unter Key Management einen Key anlegen.
  3. /yatb keys add ausführen und Novita wählen.

Tarif

Nur bezahlte Keys (Projekt/Konto mit Abrechnung) sind nutzbar.

Datenschutz

Laut Nutzungsbedingungen: Zero Data Retention und standardmäßig kein Training mit deinen Inhalten. Nutzungs-Metadaten werden bis zu 2 Jahre aufbewahrt; Verarbeitung auch in den USA möglich (Standardvertragsklauseln). Ein DPA nur für Enterprise-Kunden. Es gilt das Recht von Delaware (USA). Google Translate Übersetzungsdienst

Schritte

  1. Öffne console.cloud.google.com und lege ein Projekt an.
  2. Aktiviere die Cloud Translation API (ein Rechnungskonto ist nötig; die ersten 500.000 Zeichen pro Monat sind kostenlos).
  3. APIs & Dienste → Anmeldedaten → Anmeldedaten erstellen → API-Schlüssel, danach den Schlüssel auf die Cloud Translation API beschränken.
  4. /yatb keys add ausführen und Google Translate wählen.

Tarif

Kostenlose und bezahlte Keys sind möglich. Bei kostenlosen Keys gelten die Limits des Anbieters, bei bezahlten legst du ein Monatsbudget fest.

Datenschutz

Der Text wird nur für die Übersetzung im Arbeitsspeicher gehalten und nicht zum Trainieren oder Verbessern der Google-Übersetzung genutzt. Verarbeitung durch Google weltweit. Datenschutzangaben des Anbieters

Azure Translator Übersetzungsdienst

Schritte

  1. Lege in portal.azure.com eine Translator-Ressource an (Tarif F0 = 2 Mio. Zeichen pro Monat kostenlos).
  2. Öffne Schlüssel und Endpunkt: Kopiere Schlüssel 1 und Standort/Region (z. B. westeurope).
  3. /yatb keys add ausführen, Azure Translator wählen und Key und Region eintragen.

Tarif

Kostenlose und bezahlte Keys sind möglich. Bei kostenlosen Keys gelten die Limits des Anbieters, bei bezahlten legst du ein Monatsbudget fest.

Datenschutz

Die Textübersetzung speichert den Text nicht ("No Trace"). YATB nutzt den globalen Endpunkt, daher können Anfragen in jedem Microsoft-Rechenzentrum verarbeitet werden, meist im nächstgelegenen. Datenschutzangaben des Anbieters
