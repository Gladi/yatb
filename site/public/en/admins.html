For server admins

YATB is a private bot. If it is on your server, this is how you set it up. All commands are under /yatb and only visible to admins.

Setup in 5 steps

  1. Check permissions. In every linked channel YATB needs: View Channel, Read Message History, Manage Webhooks, Create Public Threads, Send Messages in Threads, Manage Threads, Add Reactions.
  2. Link channels. Channels with the same bridge name are translated into each other:
    /yatb bridge add chat #english English
    /yatb bridge add chat #deutsch German
    Forum and media channels work the same way - always forum with forum. YATB creates missing tags itself if it may Manage Channels in the forum.
  3. Add API keys (optional). Without keys YATB uses LibreTranslate. For better quality add keys with /yatb keys add - see API keys.
  4. Set a log channel. /yatb log set - YATB reports usage warnings, key problems and changes there.
  5. Inform your members. Link to the member guide or add a short rule, for example:
    Translation (YATB): In linked channels, the bot YATB translates messages automatically and reposts them under your name. For this they may be sent to external services (e.g. AI providers, Google). Message texts are not stored. Local-only translation: /yatb-user privacy

/yatb status shows the translation chain of your server and the state of every service.

The translation chain

For every message YATB tries the services in this order and takes the first good result:

  1. AI providers with your keys - better quality group first, free keys before paid keys
  2. Google Translate
  3. Azure Translator
  4. LibreTranslate on our own server - always available
  5. [Raw] - the original text, if nothing else worked

Every answer is checked (mentions, links, formatting). A bad answer, an error or an exhausted limit moves on to the next service; a failing service is skipped for a while. Members with Local only always get LibreTranslate.

Usage, limits and budget

  • Free keys: YATB counts usage against the provider's free limits per minute, day and month.
  • Paid keys: you set a monthly budget in USD or EUR. YATB estimates the cost from the list prices - set a spending limit at the provider as well.
  • Daily limits reset at 00:00 UTC, monthly limits on the 1st at 00:00 UTC.
  • Warnings at 90, 95 and 100 % go to the log channel. When a key is used up, the next service takes over.
  • If the same key is used on several servers, usage is counted together. Other servers are never named.
  • /yatb keys list shows usage per key, /yatb keys edit changes plan, budget and limit.

Forum and media channels

  • Link forums like text channels, e.g. /yatb bridge add forum #forum-en English. A bridge contains either forums or text channels, never both. Media channels work the same way.
  • A new post appears in every other forum of the bridge - translated title and text, matching tags, under the author's name. Replies, edits, deletes and reactions inside the post are mirrored.
  • Renaming, retagging, closing or locking the original post is applied to the copies.
  • Tags are matched 1:1. YATB creates missing tags itself (translated name, same emoji) if it has the permission Manage Channels - otherwise only tags with the same name are matched. Discord allows 20 tags per forum.

Where to grant Manage Channels:

  • On the category of the forums (recommended): all forums in it are covered, including new ones, and the rest of the server stays protected.
  • On each forum: the narrowest option, but every new forum needs it again.
  • Server-wide (bot role or invite link): the most convenient, but the bot could then edit or delete any channel - if its token were ever stolen, the damage would be much larger.

How keys are protected

Keys are entered in a private Discord form, never as a command option. They are stored encrypted (AES-256-GCM, separate per server) and are never shown again - only the last 4 characters. This website never shows or accepts keys.

All commands

CommandDescription
/yatb infoSetup guide and overview of all commands
/yatb guideHow to get an API key for a translation service
/yatb channelsHow many channels this server uses (Discord limit: 500)
/yatb statusTranslation chain, usage and service health of this server
/yatb bridge addAdd a channel to a translation bridge
/yatb bridge removeRemove a channel from its bridge
/yatb bridge listList all bridges of this server
/yatb keys addAdd an API key (entered in a private form, stored encrypted)
/yatb keys editChange the settings of a key (the key itself is never shown)
/yatb keys listShow this server's API keys and their usage (never the keys themselves)
/yatb keys removeRemove an API key from this server
/yatb log setSet the channel for notifications (usage warnings, key problems, changes)
/yatb log clearTurn off the notification channel
/yatb resetDelete all bridges, keys and settings of this server
/yatb uninstallDelete all data of this server and make the bot leave
/yatb-user privacyChoose who may translate your messages (applies on all servers)
/yatb-user helpWhat this bot does with your messages

Removing YATB

/yatb reset deletes all bridges, keys and settings of your server. /yatb uninstall deletes all data of your server and the bot leaves.
