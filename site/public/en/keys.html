Getting API keys

API keys make translations better than the free LibreTranslate. Each key belongs to you or your server - YATB only uses it for your server and stores it encrypted.

  • Set a spending limit in your provider account in addition to the budget in YATB.
  • Where available, switch on zero data retention or switch off training on your data.
  • Add keys with /yatb keys add: choose the provider, then paste the key into the private form.
  • Google Gemini
  • Mistral
  • Groq
  • Novita
  • Google Translate
  • Azure Translator

Google Gemini AI provider

Steps

  1. Open aistudio.google.com and sign in with your Google account.
  2. Create or choose a Google Cloud project and enable billing for it - the free tier may not be used for users in the EEA, UK or Switzerland.
  3. Get API key → Create API key for this project.
  4. Run /yatb keys add, choose Google Gemini and paste the key.

Plan

Only paid keys (project/account with billing) can be used.

Privacy

Only keys with billing enabled - the free tier may not be used for users in the EEA, the UK or Switzerland. Paid tier: Google does not use the content to improve its products; prompts are logged for a limited time to detect abuse. Processed by Google worldwide. Provider's privacy information

Mistral AI provider

Steps

  1. Sign in at console.mistral.ai.
  2. Under Billing choose a paid plan (the free Experiment plan may use your data for training).
  3. API Keys → Create new key.
  4. Run /yatb keys add, choose Mistral and paste the key.

Plan

Free and paid keys are possible. With a free key the provider's limits apply; with a paid key you set a monthly budget.

Privacy

Mistral AI (France). No training on your content - except where a product setting allows it: in the Mistral console under Privacy, switch off the use of API data for improvement. The free plan may use data for training unless you opt out. A DPA is available, zero data retention on request. Provider's privacy information

Groq AI provider

Steps

  1. Sign in at console.groq.com.
  2. Recommended: enable zero data retention under Settings → Data Controls.
  3. API Keys → Create API Key.
  4. Run /yatb keys add and choose Groq. The free plan has low limits (about 30 requests per minute).

Plan

Free and paid keys are possible. With a free key the provider's limits apply; with a paid key you set a monthly budget.

Privacy

By default Groq does not keep inference data; logs for troubleshooting or abuse are kept up to 30 days. Zero data retention can be switched on for everyone under Data Controls. Data is stored in the USA. Provider's privacy information

Open console →

Novita AI provider

Steps

  1. Sign in at novita.ai and add credit (there is no free plan).
  2. Create a key under Key Management.
  3. Run /yatb keys add and choose Novita.

Plan

Only paid keys (project/account with billing) can be used.

Privacy

According to its terms: zero data retention and no training on your content by default. Usage metadata is kept up to 2 years; data may be processed in the USA (SCC). A DPA only for enterprise customers. Governed by the law of Delaware, USA. Provider's privacy information

Google Translate Translation service

Steps

  1. Open console.cloud.google.com and create a project.
  2. Enable the Cloud Translation API (a billing account is required; the first 500,000 characters per month are free).
  3. APIs & Services → Credentials → Create credentials → API key, then restrict the key to the Cloud Translation API.
  4. Run /yatb keys add and choose Google Translate.

Plan

Free and paid keys are possible. With a free key the provider's limits apply; with a paid key you set a monthly budget.

Privacy

The text is only held in memory for the translation and is not used to train or improve Google's translation. Processed by Google worldwide. Provider's privacy information

Open console →

Azure Translator Translation service

Steps

  1. In portal.azure.com create a Translator resource (pricing tier F0 = 2 million characters per month free).
  2. Open Keys and Endpoint: copy Key 1 and the Location/Region (e.g. westeurope).
  3. Run /yatb keys add, choose Azure Translator and enter key and region.

Plan

Free and paid keys are possible. With a free key the provider's limits apply; with a paid key you set a monthly budget.

Privacy

Text translation does not store the text ("no trace"). YATB uses the global endpoint, so requests may be processed in any Microsoft data center, usually the nearest one. Provider's privacy information
