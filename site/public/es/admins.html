Para administradores de servidores

YATB es un bot privado. Si está en tu servidor, así es como debes configurarlo. Todos los comandos están bajo /yatb y solo son visibles para los administradores.

Configuración en 5 pasos

  1. Comprueba los permisos. En cada canal vinculado, YATB necesita: View Channel, Read Message History, Manage Webhooks, Create Public Threads, Send Messages in Threads, Manage Threads, Add Reactions.
  2. Vincula canales. Los canales con el mismo nombre de Bridge se traducen entre sí:
    /yatb bridge add chat #english English
    /yatb bridge add chat #deutsch German
    Los canales de foro y multimedia funcionan de la misma manera: siempre foro con foro. YATB crea las etiquetas faltantes por sí mismo si tiene permiso para Gestionar canales en el foro.
  3. Añade claves API (opcional). Sin claves, YATB utiliza LibreTranslate. Para obtener una mejor calidad, añade claves con /yatb keys add; consulta claves API.
  4. Configura un canal de registro. /yatb log set - YATB informa ahí de advertencias de uso, problemas con las claves y cambios.
  5. Informa a tus miembros. Enlaza a la guía para miembros o añade una norma breve, por ejemplo:
    Traducción (YATB): En los canales enlazados, el bot YATB traduce los mensajes automáticamente y los vuelve a publicar bajo tu nombre. Para ello, pueden enviarse a servicios externos (p. ej., proveedores de IA, Google). Los textos de los mensajes no se almacenan. Traducción Solo local: /yatb-user privacy

/yatb status muestra la cadena de traducción de tu servidor y el estado de cada servicio.

La cadena de traducción

Para cada mensaje, YATB prueba los servicios en este orden y toma el primer resultado válido:

  1. Proveedores de IA con tus claves: primero el grupo de mejor calidad, claves gratuitas antes que claves de pago
  2. Google Translate
  3. Azure Translator
  4. LibreTranslate en nuestro propio servidor: siempre disponible
  5. [Raw] - el texto original, si nada más ha funcionado

Cada respuesta se verifica (menciones, enlaces, formato). Una respuesta incorrecta, un error o un límite agotado pasan al siguiente servicio; un servicio que falla se omite durante un tiempo. Los miembros con Solo local siempre obtienen LibreTranslate.

Uso, límites y presupuesto

  • Claves gratuitas: YATB contabiliza el uso según los límites gratuitos del proveedor por minuto, día y mes.
  • Claves de pago: estableces un presupuesto mensual en USD o EUR. YATB estima el coste a partir de los precios de lista; establece también un límite de gasto en el proveedor.
  • Los límites diarios se reinician a las 00:00 UTC, los mensuales el día 1 a las 00:00 UTC.
  • Las advertencias al 90, 95 y 100 % se envían al canal de registro. Cuando una clave se agota, el siguiente servicio toma el relevo.
  • Si se utiliza la misma clave en varios servidores, el uso se contabiliza conjuntamente. Nunca se mencionan otros servidores.
  • /yatb keys list muestra el uso por clave, /yatb keys edit cambia el plan, el presupuesto y el límite.

Canales de foro y multimedia

  • Vincula foros como canales de texto, p. ej. /yatb bridge add forum #forum-en English. Un Bridge contiene foros o canales de texto, nunca ambos. Los canales multimedia funcionan de la misma manera.
  • Una nueva publicación aparece en todos los demás foros del Bridge: título y texto traducidos, etiquetas coincidentes, bajo el nombre del autor. Las respuestas, ediciones, eliminaciones y reacciones dentro de la publicación se replican.
  • El cambio de nombre, el cambio de etiquetas, el cierre o el bloqueo de la publicación original se aplican a las copias.
  • Las etiquetas se emparejan 1:1. YATB crea las etiquetas faltantes por sí mismo (nombre traducido, mismo emoji) si tiene el permiso Gestionar canales; de lo contrario, solo se emparejan las etiquetas con el mismo nombre. Discord permite 20 etiquetas por foro.

Dónde conceder Gestionar canales:

  • En la categoría de los foros (recomendado): todos los foros dentro de ella quedan cubiertos, incluidos los nuevos, y el resto del servidor permanece protegido.
  • En cada foro: la opción más restrictiva, pero cada foro nuevo necesita el permiso de nuevo.
  • A nivel de servidor (rol del bot o enlace de invitación): la opción más cómoda, pero el bot podría editar o eliminar cualquier canal; si su token fuera robado, el daño sería mucho mayor.

Cómo se protegen las claves

Las claves se introducen en un formulario privado de Discord, nunca como una opción de comando. Se almacenan cifradas (AES-256-GCM, por separado para cada servidor) y nunca se vuelven a mostrar, solo los últimos 4 caracteres. Este sitio web nunca muestra ni acepta claves.

Todos los comandos

ComandoDescripción
/yatb infoGuía de configuración y resumen de todos los comandos
/yatb guideCómo obtener una clave API para un servicio de traducción
/yatb channelsCuántos canales usa este servidor (límite de Discord: 500)
/yatb statusCadena de traducción, uso y estado del servicio de este servidor
/yatb bridge addAñadir un canal a un puente de traducción
/yatb bridge removeEliminar un canal de su puente
/yatb bridge listListar todos los puentes de este servidor
/yatb keys addAñadir una clave API (se introduce en un formulario privado y se guarda cifrada)
/yatb keys editCambiar la configuración de una clave (la clave nunca se muestra)
/yatb keys listMostrar las claves API de este servidor y su uso (nunca las claves en sí)
/yatb keys removeEliminar una clave API de este servidor
/yatb log setEstablecer el canal para notificaciones (avisos de uso, problemas con claves, cambios)
/yatb log clearDesactivar el canal de notificaciones
/yatb resetEliminar todos los puentes, claves y ajustes de este servidor
/yatb uninstallEliminar todos los datos de este servidor y hacer que el bot se vaya
/yatb-user privacyElegir quién puede traducir tus mensajes (se aplica en todos los servidores)
/yatb-user helpQué hace este bot con tus mensajes

Eliminar YATB

/yatb reset elimina todos los Bridge, claves y ajustes de tu servidor. /yatb uninstall elimina todos los datos de tu servidor y el bot se marcha.
