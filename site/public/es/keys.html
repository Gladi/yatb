Obtención de claves API

Las claves API mejoran las traducciones respecto al LibreTranslate gratuito. Cada clave te pertenece a ti o a tu servidor; YATB solo la utiliza para tu servidor y la almacena cifrada.

  • Establece un límite de gasto en la cuenta de tu proveedor además del presupuesto en YATB.
  • Donde esté disponible, activa la retención de datos cero o desactiva el entrenamiento con tus datos.
  • Añade claves con /yatb keys add: elige el proveedor y pega la clave en el formulario privado.

Google Gemini Proveedor de IA

Pasos

  1. Abre aistudio.google.com e inicia sesión con tu cuenta de Google.
  2. Crea o elige un proyecto de Google Cloud y activa la facturación; el nivel [Free] puede no estar disponible para usuarios en el EEE, Reino Unido o Suiza.
  3. Get API key → Create API key para este proyecto.
  4. Ejecuta /yatb keys add, elige Google Gemini y pega la clave.

Plan

Solo se pueden usar claves [Paid] (proyecto/cuenta con facturación).

Privacidad

Solo claves con facturación activada: el nivel gratuito no puede utilizarse para usuarios en el EEE, el Reino Unido o Suiza. Nivel de pago: Google no utiliza el contenido para mejorar sus productos; las solicitudes se registran durante un tiempo limitado para detectar abusos. Procesado por Google a nivel mundial. Mistral Proveedor de IA

Pasos

  1. Inicia sesión en console.mistral.ai.
  2. En Billing elige un plan [Paid] (el plan [Free] Experiment puede usar tus datos para entrenamiento).
  3. API Keys → Create new key.
  4. Ejecuta /yatb keys add, elige Mistral y pega la clave.

Plan

Es posible usar claves [Free] y [Paid]. Con una clave [Free] se aplican los límites del proveedor; con una clave [Paid] estableces un presupuesto mensual.

Privacidad

Mistral AI (Francia). Sin entrenamiento con tu contenido, excepto cuando la configuración del producto lo permita: en la consola de Mistral, bajo Privacy, desactiva el uso de datos de la API para mejoras. El plan gratuito puede utilizar datos para entrenamiento a menos que lo desactives. Existe un DPA disponible y retención de datos cero bajo petición. Información de privacidad del proveedor

Groq Proveedor de IA

Pasos

  1. Inicia sesión en console.groq.com.
  2. Recomendado: activa la retención de datos cero en Settings → Data Controls.
  3. API Keys → Create API Key.
  4. Ejecuta /yatb keys add y elige Groq. El plan [Free] tiene límites bajos (unas 30 solicitudes por minuto).

Plan

Es posible usar claves [Free] y [Paid]. Con una clave [Free] se aplican los límites del proveedor; con una clave [Paid] estableces un presupuesto mensual.

Privacidad

Por defecto, Groq no conserva datos de inferencia; los registros para resolución de problemas o abusos se conservan hasta 30 días. La retención de datos cero puede activarse para todos en Data Controls. Los datos se almacenan en EE. UU. Información de privacidad del proveedor

Novita Proveedor de IA

Pasos

  1. Inicia sesión en novita.ai y añade crédito (no hay plan [Free]).
  2. Crea una clave en Key Management.
  3. Ejecuta /yatb keys add y elige Novita.

Plan

Solo se pueden usar claves [Paid] (proyecto/cuenta con facturación).

Privacidad

Según sus términos: retención de datos cero y sin entrenamiento con tu contenido por defecto. Los metadatos de uso se conservan hasta 2 años; los datos pueden procesarse en EE. UU. (SCC). Un DPA solo para clientes empresariales. Regido por la ley de Delaware, EE. UU. Información de privacidad del proveedor

Google Translate Servicio de traducción

Pasos

  1. Abre console.cloud.google.com y crea un proyecto.
  2. Activa la Cloud Translation API (se requiere una cuenta de facturación; los primeros 500.000 caracteres al mes son [Free]).
  3. APIs & Services → Credentials → Create credentials → API key, luego restringe la clave a la Cloud Translation API.
  4. Ejecuta /yatb keys add y elige Google Translate.

Plan

Es posible usar claves [Free] y [Paid]. Con una clave [Free] se aplican los límites del proveedor; con una clave [Paid] estableces un presupuesto mensual.

Privacidad

El texto solo se mantiene en la memoria para la traducción y no se utiliza para entrenar o mejorar la traducción de Google. Procesado por Google a nivel mundial. Información de privacidad del proveedor

Azure Translator Servicio de traducción

Pasos

  1. En portal.azure.com crea un recurso Translator (nivel de precios F0 = 2 millones de caracteres al mes [Free]).
  2. Abre Keys and Endpoint: copia Key 1 y la Location/Region (ej. westeurope).
  3. Ejecuta /yatb keys add, elige Azure Translator e introduce la clave y la región.

Plan

Es posible usar claves [Free] y [Paid]. Con una clave [Free] se aplican los límites del proveedor; con una clave [Paid] estableces un presupuesto mensual.

Privacidad

La traducción de texto no almacena el texto ("sin rastro"). YATB utiliza el punto de conexión global, por lo que las solicitudes pueden procesarse en cualquier centro de datos de Microsoft, generalmente el más cercano. Información de privacidad del proveedor
