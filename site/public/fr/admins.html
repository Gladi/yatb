Pour les administrateurs de serveur

YATB est un bot privé. S'il est présent sur ton serveur, voici comment le configurer. Toutes les commandes se trouvent sous /yatb et ne sont visibles que par les administrateurs.

Configuration en 5 étapes

  1. Vérifie les permissions. Dans chaque canal lié, YATB a besoin de : View Channel, Read Message History, Manage Webhooks, Create Public Threads, Send Messages in Threads, Manage Threads, Add Reactions.
  2. Relie les salons. Les salons portant le même nom de Bridge sont traduits les uns vers les autres :
    /yatb bridge add chat #english English
    /yatb bridge add chat #deutsch German
    Les salons de forum et de médias fonctionnent de la même manière - toujours forum avec forum. YATB crée lui-même les tags manquants s'il dispose de la permission Gérer les salons dans le forum.
  3. Ajoute des clés API (optionnel). Sans clés, YATB utilise LibreTranslate. Pour une meilleure qualité, ajoute des clés avec /yatb keys add - voir clés API.
  4. Définit un canal de journalisation. /yatb log set - YATB y signale les avertissements d'utilisation, les problèmes de clés et les changements.
  5. Informe tes membres. Fais un lien vers le guide des membres ou ajoute une règle courte, par exemple :
    Traduction (YATB) : Dans les canaux liés, le bot YATB traduit automatiquement les messages et les republie sous ton nom. Pour cela, ils peuvent être envoyés à des services externes (ex. : fournisseurs d'IA, Google). Les textes des messages ne sont pas stockés. Traduction Local uniquement : /yatb-user privacy

/yatb status affiche la chaîne de traduction de ton serveur et l'état de chaque service.

La chaîne de traduction

Pour chaque message, YATB essaie les services dans cet ordre et retient le premier résultat valide :

  1. Fournisseurs d'IA avec tes clés - groupe de meilleure qualité d'abord, clés gratuites avant les clés payantes
  2. Google Translate
  3. Azure Translator
  4. LibreTranslate sur notre propre serveur - toujours disponible
  5. [Raw] - le texte original, si rien d'autre n'a fonctionné

Chaque réponse est vérifiée (mentions, liens, formatage). Une mauvaise réponse, une erreur ou une limite atteinte passe au service suivant ; un service défaillant est ignoré pendant un certain temps. Les membres en Local uniquement utilisent toujours LibreTranslate.

Utilisation, limites et budget

  • Clés gratuites : YATB compte l'utilisation par rapport aux limites gratuites du fournisseur par minute, jour et mois.
  • Clés payantes : tu définis un budget mensuel en USD ou EUR. YATB estime le coût à partir des tarifs publics — définis aussi une limite de dépenses chez le fournisseur.
  • Les limites quotidiennes se réinitialisent à 00:00 UTC, les limites mensuelles le 1er à 00:00 UTC.
  • Des avertissements à 90, 95 et 100 % sont envoyés dans le canal de log. Quand une clé est épuisée, le service suivant prend le relais.
  • Si la même clé est utilisée sur plusieurs serveurs, l'utilisation est comptabilisée ensemble. Les autres serveurs ne sont jamais nommés.
  • /yatb keys list et le tableau de bord affichent l'utilisation par clé, /yatb keys edit permet de modifier le plan, le budget et la limite.

Tableau de bord

Dans le tableau de bord, connecte-toi avec Discord et vois tous les serveurs avec YATB sur lesquels tu es administrateur·rice.

  • Utilisation par clé API : aujourd'hui et ce mois-ci, par rapport aux limites gratuites ou à ton budget — les données se mettent à jour automatiquement.
  • Modifie l'étiquette, le plan, le budget et la limite d'une clé, ou supprime une clé. La clé elle-même n'est jamais affichée ni saisie sur le site — l'ajout d'une clé reste un formulaire sur Discord.
  • Change l'ordre de la chaîne de traduction.
  • Statistiques sur 7, 30 et 90 jours : appels, succès et volume par service.
  • Toute modification est signalée dans le canal de log du serveur avec ton nom.

Forums et salons médias

  • Relie des forums comme des salons textuels, par ex. /yatb bridge add forum #forum-en English. Un Bridge contient soit des forums, soit des salons textuels, jamais les deux. Les salons médias fonctionnent de la même manière.
  • Une nouvelle publication apparaît dans tous les autres forums du Bridge - titre et texte traduits, tags correspondants, sous le nom de l'auteur. Les réponses, modifications, suppressions et réactions au sein de la publication sont répliquées.
  • Le renommage, le changement de tags, la fermeture ou le verrouillage de la publication originale sont appliqués aux copies.
  • Les tags sont mis en correspondance 1:1. YATB crée lui-même les tags manquants (nom traduit, même émoji) s'il dispose de la permission Gérer les salons - sinon, seuls les tags portant le même nom sont mis en correspondance. Discord autorise 20 tags par forum.

Où accorder la permission Gérer les salons :

  • Sur la catégorie des forums (recommandé) : tous les forums qu'elle contient sont couverts, y compris les nouveaux, et le reste du serveur reste protégé.
  • Sur chaque forum : l'option la plus restrictive, mais chaque nouveau forum nécessite de la configurer à nouveau.
  • À l'échelle du serveur (rôle du bot ou lien d'invitation) : le plus pratique, mais le bot pourrait alors modifier ou supprimer n'importe quel salon - si son jeton était volé, les dégâts seraient beaucoup plus importants.

Comment les clés sont protégées

Les clés sont saisies dans un formulaire Discord privé, jamais en tant qu'option de commande. Elles sont stockées de manière chiffrée (AES-256-GCM, séparées par serveur) et ne sont plus jamais affichées - seuls les 4 derniers caractères le sont. Ce site web n'affiche ni n'accepte jamais de clés.

Toutes les commandes

CommandeDescription
/yatb infoGuide de configuration et aperçu de toutes les commandes
/yatb guideComment obtenir une clé API pour un service de traduction
/yatb channelsNombre de salons utilisés sur ce serveur (limite Discord : 500)
/yatb statusChaîne de traduction, utilisation et état du service de ce serveur
/yatb bridge addAjouter un salon à un pont de traduction
/yatb bridge removeSupprimer un salon de son pont
/yatb bridge listLister tous les ponts de ce serveur
/yatb keys addAjouter une clé API (saisie dans un formulaire privé, stockée chiffrée)
/yatb keys editModifier les paramètres d'une clé (la clé elle-même n'est jamais affichée)
/yatb keys listAfficher les clés API de ce serveur et leur utilisation (jamais les clés elles-mêmes)
/yatb keys removeSupprimer une clé API de ce serveur
/yatb log setDéfinir le salon pour les notifications (avertissements d'utilisation, problèmes de clé, changements
/yatb log clearDésactiver le salon de notification
/yatb resetSupprimer tous les ponts, clés et paramètres de ce serveur
/yatb uninstallSupprimer toutes les données de ce serveur et faire quitter le bot
/yatb-user privacyChoisir qui peut traduire tes messages (s'applique sur tous les serveurs)
/yatb-user helpCe que ce bot fait de tes messages

Supprimer YATB

/yatb reset supprime tous les Bridge, clés et paramètres de ton serveur. /yatb uninstall supprime toutes les données de ton serveur et le bot quitte le serveur.
