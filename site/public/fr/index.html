Communique au-delà des langues sur Discord

YATB - Yet Another Translation Bot - relie des salons dans différentes langues. Chacun écrit dans sa propre langue, YATB publie la traduction dans les autres salons, sous le nom et l'avatar de l'auteur.

  • 7 langues
  • Aucun texte de message stocké
  • Bot privé

Ce que fait YATB

Traductions naturelles

Une traduction par IA qui comprend la conversation : l'argot, le jargon de jeu et les réponses courtes sont traduits correctement. Si un service échoue, le suivant prend le relais.

Préserve le formatage Discord

Le gras, les listes, les citations, les spoilers, les emojis, les mentions et les liens restent intacts. Le vrai code n'est pas traduit.

Reflète la conversation

Les réponses, modifications, suppressions, réactions et fils de discussion sont répliqués dans tous les canaux liés. Les annonces des canaux suivis sont également traduites.

Confidentialité dès la conception

Aucun texte de message n'est stocké. Chaque membre peut choisir que ses messages ne soient traduits que sur notre propre serveur.

Tes clés, ton budget

Les administrateurs de serveur ajoutent leurs propres clés API dans un formulaire privé. Les clés sont stockées de manière chiffrée et ne sont plus jamais affichées. Limites et alertes budgétaires incluses.

Toujours une traduction

Sans aucune clé, YATB traduit avec LibreTranslate sur notre propre serveur - gratuitement, et rien ne quitte le serveur.

Comment ça marche

  1. Les admins lient des canaux - par exemple #english et #deutsch - dans un Bridge.
  2. Les membres écrivent simplement dans leur langue. Aucune commande n'est nécessaire.
  3. YATB publie la traduction dans les autres canaux en quelques secondes.

Puis-je ajouter YATB à mon serveur ?

Pas pour le moment. YATB est un bot privé qui ne fonctionne que sur des serveurs sélectionnés. Si YATB est déjà sur ton serveur, consulte les guides pour les membres et pour les admins.

Tu aimes YATB ?

YATB est gratuit et sans publicité. Si tu souhaites aider à couvrir les frais de fonctionnement, tu peux nous soutenir sur Ko-fi.
