Obtenir des clés API

Les clés API permettent d'obtenir de meilleures traductions que le service gratuit LibreTranslate. Chaque clé t'appartient ou appartient à ton serveur - YATB ne l'utilise que pour ton serveur et la stocke de manière chiffrée.

  • Définis une limite de dépenses dans ton compte fournisseur en plus du budget dans YATB.
  • Si disponible, active la non-rétention des données ou désactive l'entraînement sur tes données.
  • Ajoute des clés avec /yatb keys add : choisis le fournisseur, puis colle la clé dans le formulaire privé.

Google Gemini Fournisseur d'IA

Étapes

  1. Ouvre aistudio.google.com et connecte-toi avec ton compte Google.
  2. Crée ou choisis un projet Google Cloud et active la facturation - le niveau [Free] peut ne pas être disponible pour les utilisateurs de l'EEE, du Royaume-Uni ou de Suisse.
  3. Get API key → Create API key pour ce projet.
  4. Utilise /yatb keys add, choisis Google Gemini et colle la clé.

Forfait

Seules les clés [Paid] (projet/compte avec facturation) peuvent être utilisées.

Confidentialité

Uniquement pour les clés avec facturation activée - le niveau gratuit ne peut pas être utilisé pour les utilisateurs de l'EEE, du Royaume-Uni ou de Suisse. Niveau payant : Google n'utilise pas le contenu pour améliorer ses produits ; les requêtes sont enregistrées pendant une durée limitée pour détecter les abus. Traité par Google dans le monde entier. Mistral Fournisseur d'IA

Étapes

  1. Connecte-toi sur console.mistral.ai.
  2. Dans Billing, choisis un forfait [Paid] (le forfait [Free] Experiment peut utiliser tes données pour l'entraînement).
  3. API Keys → Create new key.
  4. Utilise /yatb keys add, choisis Mistral et colle la clé.

Forfait

Les clés [Free] et [Paid] sont possibles. Avec une clé [Free], les limites du fournisseur s'appliquent ; avec une clé [Paid], tu définis un budget mensuel.

Confidentialité

Mistral AI (France). Aucun entraînement sur ton contenu - sauf si un paramètre du produit le permet : dans la console Mistral sous Privacy, désactive l'utilisation des données API pour l'amélioration. Le forfait gratuit peut utiliser les données pour l'entraînement, sauf si tu t'y opposes. Un DPA est disponible, aucune conservation des données sur demande. Informations de confidentialité du fournisseur

Ouvrir la console →

Groq Fournisseur d'IA

Étapes

  1. Connecte-toi sur console.groq.com.
  2. Recommandé : active la rétention de données zéro dans Settings → Data Controls.
  3. API Keys → Create API Key.
  4. Utilise /yatb keys add et choisis Groq. Le forfait [Free] a des limites basses (environ 30 requêtes par minute).

Forfait

Les clés [Free] et [Paid] sont possibles. Avec une clé [Free], les limites du fournisseur s'appliquent ; avec une clé [Paid], tu définis un budget mensuel.

Confidentialité

Par défaut, Groq ne conserve pas les données d'inférence ; les journaux pour le dépannage ou les abus sont conservés jusqu'à 30 jours. La conservation zéro des données peut être activée pour tout le monde sous Data Controls. Les données sont stockées aux États-Unis. Informations de confidentialité du fournisseur

Ouvrir la console →

Novita Fournisseur d'IA

Étapes

  1. Connecte-toi sur novita.ai et ajoute du crédit (il n'y a pas de forfait [Free]).
  2. Crée une clé dans Key Management.
  3. Utilise /yatb keys add et choisis Novita.

Forfait

Seules les clés [Paid] (projet/compte avec facturation) peuvent être utilisées.

Confidentialité

Selon ses conditions : aucune conservation des données et aucun entraînement sur ton contenu par défaut. Les métadonnées d'utilisation sont conservées jusqu'à 2 ans ; les données peuvent être traitées aux États-Unis (SCC). Un DPA est disponible uniquement pour les clients entreprises. Régie par la loi du Delaware, États-Unis. Informations de confidentialité du fournisseur

Google Translate Service de traduction

Étapes

  1. Ouvre console.cloud.google.com et crée un projet.
  2. Active la Cloud Translation API (un compte de facturation est requis ; les 500 000 premiers caractères par mois sont [Free]).
  3. APIs & Services → Credentials → Create credentials → API key, puis restreins la clé à la Cloud Translation API.
  4. Utilise /yatb keys add et choisis Google Translate.

Forfait

Les clés [Free] et [Paid] sont possibles. Avec une clé [Free], les limites du fournisseur s'appliquent ; avec une clé [Paid], tu définis un budget mensuel.

Confidentialité

Le texte est uniquement conservé en mémoire pour la traduction et n'est pas utilisé pour entraîner ou améliorer la traduction de Google. Traité par Google dans le monde entier. Informations de confidentialité du fournisseur

Azure Translator Service de traduction

Étapes

  1. Dans portal.azure.com, crée une ressource Translator (niveau tarifaire F0 = 2 millions de caractères par mois [Free]).
  2. Ouvre Keys and Endpoint : copie Key 1 et la Location/Region (ex: westeurope).
  3. Utilise /yatb keys add, choisis Azure Translator et saisis la clé et la région.

Forfait

Les clés [Free] et [Paid] sont possibles. Avec une clé [Free], les limites du fournisseur s'appliquent ; avec une clé [Paid], tu définis un budget mensuel.

Confidentialité

La traduction de texte ne stocke pas le texte (« no trace »). YATB utilise le point de terminaison global, les requêtes peuvent donc être traitées dans n'importe quel centre de données Microsoft, généralement le plus proche. Informations de confidentialité du fournisseur
