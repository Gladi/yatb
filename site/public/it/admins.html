Per gli amministratori del server

YATB è un bot privato. Se è presente sul tuo server, ecco come configurarlo. Tutti i comandi sono sotto /yatb e visibili solo agli amministratori.

Configurazione in 5 passaggi

  1. Controlla i permessi. In ogni canale collegato YATB necessita di: View Channel, Read Message History, Manage Webhooks, Create Public Threads, Send Messages in Threads, Manage Threads, Add Reactions.
  2. Collega i canali. I canali con lo stesso nome di Bridge vengono tradotti tra loro:
    /yatb bridge add chat #english English
    /yatb bridge add chat #deutsch German
    I canali forum e media funzionano allo stesso modo: sempre forum con forum. YATB crea da solo i tag mancanti se ha il permesso di Gestire i canali nel forum.
  3. Aggiungi chiavi API (opzionale). Senza chiavi YATB utilizza LibreTranslate. Per una qualità migliore aggiungi le chiavi con /yatb keys add - vedi chiavi API.
  4. Imposta un canale di log. /yatb log set - YATB vi segnalerà avvisi sull'utilizzo, problemi con le chiavi e modifiche.
  5. Informa i tuoi membri. Inserisci un link alla guida per i membri o aggiungi una breve regola, ad esempio:
    Traduzione (YATB): Nei canali collegati, il bot YATB traduce automaticamente i messaggi e li ripubblica a tuo nome. Per farlo, i testi potrebbero essere inviati a servizi esterni (es. provider AI, Google). I testi dei messaggi non vengono archiviati. Traduzione Solo locale: /yatb-user privacy

/yatb status mostra la catena di traduzione del tuo server e lo stato di ogni servizio.

La catena di traduzione

Per ogni messaggio, YATB prova i servizi in questo ordine e utilizza il primo risultato valido:

  1. Provider AI con le tue chiavi - prima i gruppi di qualità migliore, poi le chiavi gratuite e infine quelle a pagamento
  2. Google Translate
  3. Azure Translator
  4. LibreTranslate sul nostro server - sempre disponibile
  5. [Raw] - il testo originale, se nient'altro ha funzionato

Ogni risposta viene controllata (menzioni, link, formattazione). Una risposta errata, un errore o un limite raggiunto fanno passare al servizio successivo; un servizio non funzionante viene ignorato per un po'. I membri con Solo locale ricevono sempre LibreTranslate.

Utilizzo, limiti e budget

  • Chiavi gratuite: YATB conteggia l'utilizzo rispetto ai limiti gratuiti del provider al minuto, al giorno e al mese.
  • Chiavi a pagamento: imposti un budget mensile in USD o EUR. YATB stima il costo in base alle tariffe pubblicate: imposta anche un limite di spesa sul provider.
  • I limiti giornalieri si resettano alle 00:00 UTC, quelli mensili il 1° del mese alle 00:00 UTC.
  • Avvisi al 90, 95 e 100% vengono inviati al canale log. Quando una chiave è esaurita, subentra il servizio successivo.
  • Se la stessa chiave viene usata su più server, l'utilizzo viene conteggiato insieme. Gli altri server non vengono mai menzionati.
  • /yatb keys list e il pannello mostrano l'utilizzo per chiave, /yatb keys edit modifica piano, budget e limite.

Pannello di controllo

Nel pannello di controllo accedi con Discord e vedi tutti i server con YATB di cui sei amministratore.

  • Utilizzo per chiave API: oggi e questo mese, rispetto ai limiti gratuiti o al tuo budget - si aggiorna automaticamente.
  • Modifica l'etichetta, il piano, il budget e il limite di una chiave, oppure rimuovila. La chiave vera e propria non viene mai mostrata o inserita sul sito: aggiungere una chiave resta un modulo su Discord.
  • Modifica l'ordine della catena di traduzione.
  • Statistiche per 7, 30 e 90 giorni: chiamate, successo e volume per servizio.
  • Ogni modifica viene segnalata nel canale log del server con il tuo nome.

Forum e canali media

  • Collega i forum come i canali testuali, ad esempio /yatb bridge add forum #forum-en English. Un Bridge contiene solo forum o solo canali testuali, mai entrambi. I canali media funzionano allo stesso modo.
  • Un nuovo post appare in ogni altro forum del Bridge: titolo e testo tradotti, tag corrispondenti, sotto il nome dell'autore. Risposte, modifiche, eliminazioni e reazioni all'interno del post vengono replicate.
  • La ridenominazione, la modifica dei tag, la chiusura o il blocco del post originale vengono applicati alle copie.
  • I tag vengono abbinati 1:1. YATB crea da solo i tag mancanti (nome tradotto, stessa emoji) se dispone dell'autorizzazione Gestisci canali; in caso contrario, vengono abbinati solo i tag con lo stesso nome. Discord consente 20 tag per forum.

Dove concedere Gestisci canali:

  • Sulla categoria dei forum (consigliato): tutti i forum al suo interno sono coperti, inclusi quelli nuovi, e il resto del server rimane protetto.
  • Su ogni singolo forum: l'opzione più restrittiva, ma ogni nuovo forum necessita nuovamente dell'autorizzazione.
  • A livello di server (ruolo del bot o link d'invito): la più comoda, ma il bot potrebbe modificare o eliminare qualsiasi canale; se il suo token venisse rubato, il danno sarebbe molto maggiore.

Come sono protette le chiavi

Le chiavi vengono inserite in un modulo privato di Discord, mai come opzione di comando. Vengono archiviate crittografate (AES-256-GCM, separatamente per ogni server) e non vengono mai mostrate di nuovo, ad eccezione degli ultimi 4 caratteri. Questo sito web non mostra né accetta mai chiavi.

Tutti i comandi

ComandoDescrizione
/yatb infoGuida alla configurazione e panoramica di tutti i comandi
/yatb guideCome ottenere una chiave API per un servizio di traduzione
/yatb channelsQuanti canali utilizza questo server (limite Discord: 500)
/yatb statusCatena di traduzione, utilizzo e stato del servizio di questo server
/yatb bridge addAggiungi un canale a un Bridge di traduzione
/yatb bridge removeRimuovi un canale dal suo Bridge
/yatb bridge listElenca tutti i Bridge di questo server
/yatb keys addAggiungi una chiave API (inserita in un modulo privato, salvata criptata)
/yatb keys editModifica le impostazioni di una chiave (la chiave stessa non viene mai mostrata)
/yatb keys listMostra le chiavi API di questo server e il loro utilizzo (mai le chiavi stesse)
/yatb keys removeRimuovi una chiave API da questo server
/yatb log setImposta il canale per le notifiche (avvisi di utilizzo, problemi con le chiavi, modifiche)
/yatb log clearDisattiva il canale delle notifiche
/yatb resetElimina tutti i Bridge, le chiavi e le impostazioni di questo server
/yatb uninstallElimina tutti i dati di questo server e fai uscire il bot
/yatb-user privacyScegli chi può tradurre i tuoi messaggi (si applica a tutti i server)
/yatb-user helpCosa fa questo bot con i tuoi messaggi

Rimozione di YATB

/yatb reset elimina tutti i Bridge, le chiavi e le impostazioni del tuo server. /yatb uninstall elimina tutti i dati del tuo server e il bot esce.
