Ottenere chiavi API

Le chiavi API rendono le traduzioni migliori rispetto al LibreTranslate gratuito. Ogni chiave appartiene a te o al tuo server: YATB la utilizza solo per il tuo server e la archivia crittografata.

  • Imposta un limite di spesa nell'account del tuo provider oltre al budget in YATB.
  • Dove disponibile, attiva la conservazione zero dei dati o disattiva l'addestramento sui tuoi dati.
  • Aggiungi chiavi con /yatb keys add: scegli il provider, quindi incolla la chiave nel modulo privato.

Google Gemini Provider AI

Passaggi

  1. Apri aistudio.google.com e accedi con il tuo account Google.
  2. Crea o scegli un progetto Google Cloud e abilita la fatturazione (il piano [Free] potrebbe non essere utilizzabile per utenti in SEE, Regno Unito o Svizzera).
  3. Get API key → Create API key per questo progetto.
  4. Esegui /yatb keys add, scegli Google Gemini e incolla la chiave.

Piano

È possibile utilizzare solo chiavi [Paid] (progetto/account con fatturazione).

Privacy

Solo chiavi con fatturazione attiva - il piano gratuito potrebbe non essere utilizzabile per gli utenti nello SEE, nel Regno Unito o in Svizzera. Piano a pagamento: Google non utilizza i contenuti per migliorare i propri prodotti; i prompt vengono registrati per un periodo limitato per rilevare abusi. Elaborato da Google a livello globale. Mistral Provider AI

Passaggi

  1. Accedi su console.mistral.ai.
  2. Sotto Billing scegli un piano [Paid] (il piano [Free] Experiment potrebbe usare i tuoi dati per l'addestramento).
  3. API Keys → Create new key.
  4. Esegui /yatb keys add, scegli Mistral e incolla la chiave.

Piano

Sono possibili chiavi [Free] e [Paid]. Con una chiave [Free] si applicano i limiti del provider; con una chiave [Paid] imposti un budget mensile.

Privacy

Mistral AI (Francia). Nessun addestramento sui tuoi contenuti, salvo dove consentito da un'impostazione del prodotto: nella console Mistral, sotto Privacy, disattiva l'uso dei dati API per il miglioramento. Il piano gratuito potrebbe utilizzare i dati per l'addestramento a meno che tu non scelga di non partecipare. È disponibile un DPA, conservazione dei dati pari a zero su richiesta. Informativa sulla privacy del fornitore

Groq Provider AI

Passaggi

  1. Accedi su console.groq.com.
  2. Consigliato: abilita la conservazione zero dei dati in Settings → Data Controls.
  3. API Keys → Create API Key.
  4. Esegui /yatb keys add e scegli Groq. Il piano [Free] ha limiti bassi (circa 30 richieste al minuto).

Piano

Sono possibili chiavi [Free] e [Paid]. Con una chiave [Free] si applicano i limiti del provider; con una chiave [Paid] imposti un budget mensile.

Privacy

Per impostazione predefinita, Groq non conserva i dati di inferenza; i log per la risoluzione dei problemi o gli abusi vengono conservati fino a 30 giorni. La conservazione dei dati pari a zero può essere attivata per chiunque sotto Data Controls. I dati sono archiviati negli Stati Uniti. Informativa sulla privacy del fornitore

Novita Provider AI

Passaggi

  1. Accedi su novita.ai e aggiungi credito (non esiste un piano [Free]).
  2. Crea una chiave in Key Management.
  3. Esegui /yatb keys add e scegli Novita.

Piano

È possibile utilizzare solo chiavi [Paid] (progetto/account con fatturazione).

Privacy

Secondo i suoi termini: conservazione dei dati pari a zero e nessun addestramento sui tuoi contenuti per impostazione predefinita. I metadati di utilizzo vengono conservati fino a 2 anni; i dati possono essere elaborati negli Stati Uniti (SCC). Un DPA è disponibile solo per i clienti enterprise. Disciplinato dalla legge del Delaware, USA. Informativa sulla privacy del fornitore

Google Translate Servizio di traduzione

Passaggi

  1. Apri console.cloud.google.com e crea un progetto.
  2. Abilita la Cloud Translation API (è richiesto un account di fatturazione; i primi 500.000 caratteri al mese sono [Free]).
  3. APIs & Services → Credentials → Create credentials → API key, quindi limita la chiave alla Cloud Translation API.
  4. Esegui /yatb keys add e scegli Google Translate.

Piano

Sono possibili chiavi [Free] e [Paid]. Con una chiave [Free] si applicano i limiti del provider; con una chiave [Paid] imposti un budget mensile.

Privacy

Il testo viene mantenuto in memoria solo per la traduzione e non viene utilizzato per addestrare o migliorare la traduzione di Google. Elaborato da Google a livello globale. Informativa sulla privacy del fornitore

Azure Translator Servizio di traduzione

Passaggi

  1. In portal.azure.com crea una risorsa Translator (piano tariffario F0 = 2 milioni di caratteri al mese [Free]).
  2. Apri Keys and Endpoint: copia Key 1 e la Location/Region (es. westeurope).
  3. Esegui /yatb keys add, scegli Azure Translator e inserisci chiave e regione.

Piano

Sono possibili chiavi [Free] e [Paid]. Con una chiave [Free] si applicano i limiti del provider; con una chiave [Paid] imposti un budget mensile.

Privacy

La traduzione del testo non archivia il testo ("nessuna traccia"). YATB utilizza l'endpoint globale, quindi le richieste possono essere elaborate in qualsiasi data center Microsoft, solitamente quello più vicino. Informativa sulla privacy del fornitore
