API-sleutels verkrijgen

API-sleutels maken vertalingen beter dan de gratis LibreTranslate. Elke sleutel is van jou of je server - YATB gebruikt deze alleen voor jouw server en slaat deze versleuteld op.

  • Stel naast het budget in YATB ook een bestedingslimiet in bij je provideraccount.
  • Schakel waar mogelijk zero data retention in of schakel training op jouw gegevens uit.
  • Voeg sleutels toe met /yatb keys add: kies de provider en plak de sleutel in het privéformulier.
  • Google Gemini
  • Mistral
  • Groq
  • Novita
  • Google Translate
  • Azure Translator

Google Gemini AI-provider

Stappen

  1. Open aistudio.google.com en log in met je Google-account.
  2. Maak of kies een Google Cloud-project en schakel facturering in - de Free tier mag niet worden gebruikt voor gebruikers in de EER, het VK of Zwitserland.
  3. Get API key → Create API key voor dit project.
  4. Voer /yatb keys add uit, kies Google Gemini en plak de sleutel.

Plan

Alleen Paid sleutels (project/account met facturering) kunnen worden gebruikt.

Privacy

Alleen sleutels met facturering ingeschakeld - de gratis laag mag niet worden gebruikt voor gebruikers in de EER, het VK of Zwitserland. Betaalde laag: Google gebruikt de inhoud niet om zijn producten te verbeteren; prompts worden voor een beperkte tijd gelogd om misbruik op te sporen. Wordt wereldwijd door Google verwerkt. Mistral AI-provider

Stappen

  1. Log in op console.mistral.ai.
  2. Kies onder Billing een Paid plan (het gratis Experiment-plan kan je gegevens gebruiken voor training).
  3. API Keys → Create new key.
  4. Voer /yatb keys add uit, kies Mistral en plak de sleutel.

Plan

Free en Paid sleutels zijn mogelijk. Bij een Free sleutel gelden de limieten van de provider; bij een Paid sleutel stel je een maandelijks budget in.

Privacy

Mistral AI (Frankrijk). Geen training op jouw inhoud - behalve waar een productinstelling dit toestaat: schakel in de Mistral-console onder Privacy het gebruik van API-gegevens voor verbetering uit. Het gratis plan kan gegevens gebruiken voor training, tenzij je je afmeldt. Een DPA is beschikbaar, geen gegevensretentie op verzoek. Privacy-informatie van de aanbieder

Groq AI-provider

Stappen

  1. Log in op console.groq.com.
  2. Aanbevolen: schakel zero data retention in onder Settings → Data Controls.
  3. API Keys → Create API Key.
  4. Voer /yatb keys add uit en kies Groq. Het Free plan heeft lage limieten (ongeveer 30 verzoeken per minuut).

Plan

Free en Paid sleutels zijn mogelijk. Bij een Free sleutel gelden de limieten van de provider; bij een Paid sleutel stel je een maandelijks budget in.

Privacy

Standaard bewaart Groq geen inferentiegegevens; logs voor probleemoplossing of misbruik worden tot 30 dagen bewaard. Geen gegevensretentie kan voor iedereen worden ingeschakeld onder Data Controls. Gegevens worden opgeslagen in de VS. Privacy-informatie van de aanbieder

Novita AI-provider

Stappen

  1. Log in op novita.ai en voeg tegoed toe (er is geen Free plan).
  2. Maak een sleutel aan onder Key Management.
  3. Voer /yatb keys add uit en kies Novita.

Plan

Alleen Paid sleutels (project/account met facturering) kunnen worden gebruikt.

Privacy

Volgens de voorwaarden: standaard geen gegevensretentie en geen training op jouw inhoud. Gebruiksmetadata worden tot 2 jaar bewaard; gegevens kunnen in de VS worden verwerkt (SCC). Een DPA is alleen beschikbaar voor zakelijke klanten. Onderworpen aan de wetgeving van Delaware, VS. Privacy-informatie van de aanbieder

Google Translate Vertaalservice

Stappen

  1. Open console.cloud.google.com en maak een project aan.
  2. Schakel de Cloud Translation API in (een factureringsaccount is vereist; de eerste 500.000 tekens per maand zijn gratis).
  3. APIs & Services → Credentials → Create credentials → API key, beperk de sleutel vervolgens tot de Cloud Translation API.
  4. Voer /yatb keys add uit en kies Google Translate.

Plan

Free en Paid sleutels zijn mogelijk. Bij een Free sleutel gelden de limieten van de provider; bij een Paid sleutel stel je een maandelijks budget in.

Privacy

De tekst wordt alleen in het geheugen gehouden voor de vertaling en wordt niet gebruikt om de vertaling van Google te trainen of te verbeteren. Wordt wereldwijd door Google verwerkt. Privacy-informatie van de aanbieder

Azure Translator Vertaalservice

Stappen

  1. Maak in portal.azure.com een Translator-resource aan (prijsniveau F0 = 2 miljoen tekens per maand gratis).
  2. Open Keys and Endpoint: kopieer Key 1 en de Location/Region (bijv. westeurope).
  3. Voer /yatb keys add uit, kies Azure Translator en voer de sleutel en regio in.

Plan

Free en Paid sleutels zijn mogelijk. Bij een Free sleutel gelden de limieten van de provider; bij een Paid sleutel stel je een maandelijks budget in.

Privacy

Vertaaltekst slaat de tekst niet op ("no trace"). YATB gebruikt het wereldwijde eindpunt, dus verzoeken kunnen in elk Microsoft-datacenter worden verwerkt, meestal het dichtstbijzijnde. Privacy-informatie van de aanbieder
