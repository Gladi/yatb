Для администраторов сервера

YATB — это приватный бот. Если он есть на твоем сервере, вот как его настроить. Все команды находятся в /yatb и видны только администраторам.

Настройка в 5 шагов

  1. Проверь права доступа. В каждом канале Bridge боту YATB нужны: View Channel, Read Message History, Manage Webhooks, Create Public Threads, Send Messages in Threads, Manage Threads, Add Reactions.
  2. Связывай каналы. Каналы с одинаковым названием Bridge переводятся друг в друга:
    /yatb bridge add chat #english English
    /yatb bridge add chat #deutsch German
    Форумные и медиаканалы работают так же — всегда форум с форумом. YATB сам создает недостающие теги, если у него есть право Управление каналами на форуме.
  3. Добавь API-ключи (необязательно). Без ключей YATB использует LibreTranslate. Для лучшего качества добавь ключи через /yatb keys add — см. API-ключи.
  4. Укажи канал для логов. /yatb log set — YATB будет отправлять туда предупреждения об использовании, проблемы с ключами и изменения.
  5. Уведомь участников. Дай ссылку на руководство для участников или добавь краткое правило, например:
    Перевод (YATB): В связанных каналах бот YATB автоматически переводит сообщения и публикует их от твоего имени. Для этого они могут отправляться во внешние сервисы (например, ИИ-провайдеры, Google). Тексты сообщений не сохраняются. Перевод «Только локально»: /yatb-user privacy

/yatb status показывает цепочку перевода твоего сервера и состояние каждого сервиса.

Цепочка перевода

Для каждого сообщения YATB пробует сервисы в этом порядке и выбирает первый успешный результат:

  1. ИИ-провайдеры с твоими ключами — сначала группа с лучшим качеством, бесплатные ключи перед платными
  2. Google Translate
  3. Azure Translator
  4. LibreTranslate на нашем сервере — доступен всегда
  5. [Raw] — исходный текст, если ничего другое не сработало

Каждый ответ проверяется (упоминания, ссылки, форматирование). Плохой ответ, ошибка или исчерпанный лимит переводят запрос к следующему сервису; неработающий сервис временно пропускается. Участники с настройкой Только локально всегда получают LibreTranslate.

Использование, лимиты и бюджет

  • Бесплатные ключи: YATB учитывает использование в рамках бесплатных лимитов провайдера в минуту, день и месяц.
  • Платные ключи: ты устанавливаешь ежемесячный бюджет в USD или EUR. YATB оценивает стоимость по прейскуранту — также установи лимит расходов у самого провайдера.
  • Дневные лимиты сбрасываются в 00:00 UTC, месячные — 1-го числа в 00:00 UTC.
  • Предупреждения при достижении 90, 95 и 100% отправляются в канал логов. Когда ключ исчерпан, управление переходит к следующему сервису.
  • Если один и тот же ключ используется на нескольких серверах, использование суммируется. Другие серверы никогда не называются.
  • /yatb keys list показывает использование по ключу, /yatb keys edit меняет план, бюджет и лимит.

Форумы и медиаканалы

  • Связывай форумы как текстовые каналы, например, /yatb bridge add forum #forum-en English. Bridge содержит либо форумы, либо текстовые каналы, но никогда не и то, и другое вместе. Медиаканалы работают аналогично.
  • Новая публикация появляется во всех остальных форумах в составе Bridge — с переведенным заголовком и текстом, соответствующими тегами и от имени автора. Ответы, правки, удаления и реакции внутри публикации синхронизируются.
  • Переименование, изменение тегов, закрытие или блокировка исходной публикации применяются к копиям.
  • Теги сопоставляются 1:1. YATB создает недостающие теги самостоятельно (переведенное название, тот же эмодзи), если у него есть разрешение Управление каналами — в противном случае сопоставляются только теги с одинаковыми названиями. Discord позволяет использовать до 20 тегов на форум.

Где предоставить разрешение Управление каналами:

  • На категории форумов (рекомендуется): охватывает все форумы в ней, включая новые, при этом остальная часть сервера остается защищенной.
  • На каждом форуме: самый узкий вариант, но для каждого нового форума разрешение нужно выдавать заново.
  • На уровне сервера (роль бота или ссылка-приглашение): самый удобный вариант, но бот сможет редактировать или удалять любой канал — если его токен будет украден, ущерб будет значительно больше.

Как защищены ключи

Ключи вводятся в приватной форме Discord, а не в качестве аргумента команды. Они хранятся в зашифрованном виде (AES-256-GCM, отдельно для каждого сервера) и никогда не отображаются снова — только последние 4 символа. Этот сайт никогда не показывает и не принимает ключи.

Все команды

КомандаОписание
/yatb infoРуководство по настройке и обзор всех команд
/yatb guideКак получить API-ключ для сервиса перевода
/yatb channelsСколько каналов используется на этом сервере (лимит Discord: 500)
/yatb statusЦепочка перевода, использование и состояние сервисов этого сервера
/yatb bridge addДобавить канал в мост перевода
/yatb bridge removeУдалить канал из его моста
/yatb bridge listСписок всех мостов этого сервера
/yatb keys addДобавить API-ключ (вводится в приватной форме, хранится в зашифрованном виде)
/yatb keys editИзменить настройки ключа (сам ключ никогда не отображается)
/yatb keys listПоказать API-ключи этого сервера и их использование (сами ключи не отображаются)
/yatb keys removeУдалить API-ключ с этого сервера
/yatb log setУстановить канал для уведомлений (предупреждения об использовании, проблемы с ключами, изменения)
/yatb log clearОтключить канал уведомлений
/yatb resetУдалить все мосты, ключи и настройки этого сервера
/yatb uninstallУдалить все данные этого сервера и заставить бота покинуть его
/yatb-user privacyВыбрать, кто может переводить твои сообщения (применяется на всех серверах)
/yatb-user helpЧто этот бот делает с твоими сообщениями

Удаление YATB

/yatb reset удаляет все Bridge, ключи и настройки твоего сервера. /yatb uninstall удаляет все данные твоего сервера, и бот покидает его.
