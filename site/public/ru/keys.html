Получение API-ключей

API-ключи делают перевод лучше, чем бесплатный LibreTranslate. Каждый ключ принадлежит тебе или твоему серверу — YATB использует его только для твоего сервера и хранит в зашифрованном виде.

  • Установи лимит расходов в аккаунте провайдера в дополнение к бюджету в YATB.
  • Где возможно, включи отказ от хранения данных или отключи обучение на твоих данных.
  • Добавляй ключи через /yatb keys add: выбери провайдера, затем вставь ключ в приватную форму.

Google Gemini ИИ-провайдер

Шаги

  1. Открой aistudio.google.com и войди через Google-аккаунт.
  2. Создай или выбери проект Google Cloud и включи биллинг — [Free]-тариф может быть недоступен для пользователей из ЕЭЗ, Великобритании или Швейцарии.
  3. Get API key → Create API key для этого проекта.
  4. Выполни /yatb keys add, выбери Google Gemini и вставь ключ.

План

Можно использовать только платные ключи (проект/аккаунт с привязанной оплатой).

Конфиденциальность

Только ключи с включенным биллингом — бесплатный уровень может быть недоступен для пользователей в ЕЭЗ, Великобритании или Швейцарии. Платный уровень: Google не использует контент для улучшения своих продуктов; запросы логируются в течение ограниченного времени для обнаружения злоупотреблений. Обрабатывается Google по всему миру. Информация о конфиденциальности провайдера

Mistral ИИ-провайдер

Шаги

  1. Войди на console.mistral.ai.
  2. В разделе Billing выбери платный план ([Free] план Experiment может использовать твои данные для обучения).
  3. API Keys → Create new key.
  4. Выполни /yatb keys add, выбери Mistral и вставь ключ.

План

Возможны [Free] и платные ключи. С [Free]-ключом действуют лимиты провайдера; с платным ты задаешь ежемесячный бюджет.

Конфиденциальность

Mistral AI (Франция). Обучение на твоем контенте не проводится, за исключением случаев, когда это разрешено настройками продукта: в консоли Mistral в разделе Privacy отключи использование данных API для улучшения. Бесплатный план может использовать данные для обучения, если ты не откажешься от этого. Доступно DPA, нулевое хранение данных по запросу. Информация о конфиденциальности провайдера

Groq ИИ-провайдер

Шаги

  1. Войди на console.groq.com.
  2. Рекомендуется: включи нулевое хранение данных в Settings → Data Controls.
  3. API Keys → Create API Key.
  4. Выполни /yatb keys add и выбери Groq. [Free]-план имеет низкие лимиты (около 30 запросов в минуту).

План

Возможны [Free] и платные ключи. С [Free]-ключом действуют лимиты провайдера; с платным ты задаешь ежемесячный бюджет.

Конфиденциальность

По умолчанию Groq не хранит данные инференса; логи для устранения неполадок или выявления злоупотреблений хранятся до 30 дней. Нулевое хранение данных можно включить для всех в разделе Data Controls. Данные хранятся в США. Информация о конфиденциальности провайдера

Открыть консоль →

Novita ИИ-провайдер

Шаги

  1. Войди на novita.ai и пополни баланс ([Free]-плана нет).
  2. Создай ключ в Key Management.
  3. Выполни /yatb keys add и выбери Novita.

План

Можно использовать только платные ключи (проект/аккаунт с привязанной оплатой).

Конфиденциальность

Согласно условиям: нулевое хранение данных и отсутствие обучения на твоем контенте по умолчанию. Метаданные использования хранятся до 2 лет; данные могут обрабатываться в США (SCC). DPA доступно только для корпоративных клиентов. Регулируется законодательством штата Делавэр, США. Информация о конфиденциальности провайдера

Google Translate Сервис перевода

Шаги

  1. Открой console.cloud.google.com и создай проект.
  2. Включи Cloud Translation API (требуется аккаунт с биллингом; первые 500 000 символов в месяц — [Free]).
  3. APIs & Services → Credentials → Create credentials → API key, затем ограничь ключ до Cloud Translation API.
  4. Выполни /yatb keys add и выбери Google Translate.

План

Возможны [Free] и платные ключи. С [Free]-ключом действуют лимиты провайдера; с платным ты задаешь ежемесячный бюджет.

Конфиденциальность

Текст удерживается в памяти только для перевода и не используется для обучения или улучшения перевода Google. Обрабатывается Google по всему миру. Информация о конфиденциальности провайдера

Открыть консоль →

Azure Translator Сервис перевода

Шаги

  1. В portal.azure.com создай ресурс Translator (ценовой уровень F0 = 2 млн символов в месяц [Free]).
  2. Открой Keys and Endpoint: скопируй Key 1 и Location/Region (например, westeurope).
  3. Выполни /yatb keys add, выбери Azure Translator и введи ключ и регион.

План

Возможны [Free] и платные ключи. С [Free]-ключом действуют лимиты провайдера; с платным ты задаешь ежемесячный бюджет.

Конфиденциальность

Перевод текста не сохраняет сам текст («no trace»). YATB использует глобальную конечную точку, поэтому запросы могут обрабатываться в любом центре обработки данных Microsoft, обычно в ближайшем. Информация о конфиденциальности провайдера
